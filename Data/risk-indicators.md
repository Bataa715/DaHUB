## Товч тайлбар

| Нэр томьёо | Тайлбар |
|-----------|---------|
| **Хамгийн сүүлийнх** | fetchedDate-ийн хамгийн сүүлийн утгыг ав |
| **Аудит орсноос хойш** | Аудит хийгдсэн огнооноос хойш бүх утгыг харгалз |
| **Аудит орсноос хойш дундаж** | Аудитаас хойш бүх утгын дундаж |
| **Аудит орсноос хойш бүгд** | Аудитаас хойш нийт тоо/хэмжээ (нийлбэр) |
| **Range дэх дундаж** | Тодорхой мужийн доторх утгуудын дундаж |
| **HOLD** | Тухайн үзүүлэлтийг тооцохгүй (түр зогсоосон) |
| **DAY / MONTH / Q** | Oracle DAG ажиллах давтамж: өдөр / сар / улирал |
| **—** | Тогтмол давтамжгүй, шаардлагаар татна |
